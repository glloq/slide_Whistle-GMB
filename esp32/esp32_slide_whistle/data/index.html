Guide rapide

🚀 Premier démarrage

  • Connectez-vous au réseau WiFi SlideWhistle (mdp midi1234) ou via http://slidewhistle.local si STA configuré.
  • Sur le Dashboard, vérifiez que toutes les flûtes affichent l'état homed.
  • Sur Jouer, activez 🔊 (preview audio) puis cliquez sur le piano pour tester.
  • Si pas de matériel branché, lancez une Démo depuis la page Jouer.

🔧 Modules adaptatifs

Les options visibles dépendent de la configuration matérielle compilée (settings.h) :

  • Multi-flûtes : activer N flûtes via DEFAULT_FLUTE_COUNT (1 à 4 par défaut). Chaque flûte a ses pins, son canal MIDI et sa plage propres.
  • Module pression : ENABLE_PRESSURE_CONTROL. Si désactivé, la page Pression est masquée.
  • Sources MIDI : MIDI_SOURCE_SERIAL (DIN-5/UART2) et/ou MIDI_SOURCE_BLE (BLE MIDI).

🔍 Dépannage

  • Homing échoue : vérifiez que l'endstop est bien câblé avec pull-up externe (GPIO34-39 = input only). Voir Diag → Diagnostic flûtes.
  • Pas de son : vérifier dans Diag → Pression que la pompe et le réservoir sont OK. Le module pression doit être en état MAINTAIN.
  • Notes décalées : activer Utiliser la LUT dans Réglages et calibrer chaque note via l'éditeur graphique (drag des points).
  • WS déconnecte : trop de clients connectés, ou alimentation faible. Surveiller heap_min dans Diag.
  • Plusieurs flûtes silencieuses : vérifier que leurs canaux MIDI ne se chevauchent pas (sauf si voulu = unisson).

💾 Persistance

  • Toute config flûte sauvée dans NVS (namespaces flute0, flute1...).
  • Config pression : namespace pressure.
  • Presets nommés : namespace presets.
  • Pour backup hors ESP32 : Diag → Télécharger sauvegarde JSON.

📡 API REST principale

Tous les endpoints retournent JSON. Voir esp32/README.md pour la liste complète.

  • GET /api/status — état global temps-réel
  • POST /api/flute — config + plage + CC mapping
  • POST /api/flute/note — déclenche une note
  • POST /api/homing, /api/panic — contrôles globaux
  • GET /api/system — diagnostic complet
  • GET /api/midi/log[.csv] — historique MIDI
